## 实现要点

- `app/services/收据窗.py`
  - `收下回执()`（含 `接收/记录/推/提交/处理回执`、`收据入账`、`折叠回执`、`accept_receipt` 等别名）。
  - 同一事件号一把 `threading.Lock`（`取收据锁()/收据锁()`），临界区 `BEGIN IMMEDIATE` + `busy_timeout`。
  - 首张回执（或锚定窗秒内既有成功尝试）开「收据窗」并写开窗指纹；窗内第二张起只写
    「回执折叠」影子行：标记 **窗内已折叠**，说明 **窗内重复收据**，不写 `投递尝试`。
  - 同一回执号重放（含开窗原票回执号）幂等，边表不多长。
  - 窗关（`收据窗秒`，签名规可配，默认 300）后才追加一笔正式成功尝试并另开新窗。
  - 窗内重复绝不写 `死信`。
- `app/seed.py`：新表 `收据窗`（部分唯一索引：每事件至多一扇状态=开的窗）、
  `回执折叠`（回执号部分唯一索引），及兼容视图（`收据折叠/折叠记录/影子回执/回执记录` 等）。
- `app/services/互证.py`：`收据对账()`（别名 `回执对账/投递流水对账`），正式票只数
  `投递尝试`，影子只计折叠；点窗内双票异常、失锚影子；并入 `跑一次()` 总对齐。
- `app/services/签名目录.py`：`投递列表()` LEFT JOIN 折叠聚合（`折叠数/窗内折叠数/折叠标记/行末说明`）；
  `事件一条()` 带 `回执折叠/影子回执/收据窗/窗状态`；`端点列表()` 带端点折叠计数。
- `app/factory.py`：`POST /api/回执`（及 `/api/收据`、`/api/receipt(s)` 等别名）、
  GET `/api/回执`、`/api/折叠`、`/api/收据窗`、`/api/收据对账`（含 `/api/对账` 等别名）。
- 兼容服务别名模块：`回执 / 收据 / 折叠 / 幂等窗 / 回执窗 / 窗内折叠 / 收据锁 / 切流账册 / 收据窗账册 / win_fold`。
- 前端双树（`backend/app/static` 与 `/workspace/static`）同步：
  `投递流水.html`（收下回执操作条 + 原行折叠联标 + 边表）、
  `事件详情.html`（回执折叠边表）、
  `端点名册.html`（窗内折叠列）、
  `投递互证.html`（收据对账面板）。
